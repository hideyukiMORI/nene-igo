# ADR 0009 — 石のセルに碁盤の地の色の下線を引き、縦に並んだ石を 1 つずつ離して見せる

- 状態: 受理（見た目の最終判断は施主に写真で確認してもらう）
- 日付: 2026-10-26
- Issue: #7
- 影響する規則: ARC-011 / FR-07
- 補うもの: ADR 0007 の決定 3（石の塗り方）

## 文脈

Phase 3 の手順 3 で、Windows Terminal の実機の画面写真を撮った（2026-10-26・WSL2 Ubuntu 22.04・Windows Terminal・既定の 120 × 30・
ウィンドウ 1859 × 1079 ピクセル・`PrintWindow(PW_RENDERFULLCONTENT)`・撮影側は `SetProcessDPIAware`）。

- 盤の線（`+--`）・星（`*`）・座標（`I` を飛ばす列・左の行番号）・HUD・`[ ]`・キーのヘルプは配置どおりで、文字幅の崩れは無かった（画面の文字は ASCII だけ）
- 横に並んだ石は、線の桁が 1 つ残るので離れて見えた
- 🔴 **縦に並んだ石は、塗りが行の境目で接して 1 本の柱に見えた**（ADR 0007 の「結果」で予想した罠。兄弟の Reversi が ADR 0009 で踏んだものと同じ）。
  石の数を数えられない

Reversi は 1 升 3 行の最上行をあけて直した。囲碁は 1 交点 1 行で、行のあいだに行を足すと 19 路が 38 行になり、既定の 30 行に入らない（ADR 0007）。

## 決定

1. **石のセルは空白のまま、背景を石の色にし、下線（SGR 4）を碁盤の地の色で引く**。下線は文字ではなく端末が描く線なので、石のセルに文字を書かない規則（FR-07・WORK-ORDER 第 2-3 節の 4）を守ったまま、
   石の下端に碁盤の地の色の細い線が入り、縦に並んだ石のあいだが離れて見える
2. セルの見た目は閉じた enum `CellStyle`（`.plain` / `.underlined`）で持つ。下線を引くのは `Grid.paintStone` だけ
3. Terminal の `FrameEncoder` は、色を変えるたびに下線の指定を毎回明示する（引くなら 4、引かないなら 24）。前のセルの指定を引き継がない

## 強制

- **active**（テスト・`make check` の `test` 段）: 下線つきのセルは石のセルだけで、数は石の数 × 2、下線の色は碁盤の地の色、文字は空白
  （`TableRendererTests.onlyStoneCellsAreUnderlinedInTheBoardColor`）。符号化は 4 と 24 を明示する（`TerminalTests.underlineIsTurnedOnAndOffExplicitly`）
- **planned**: 見え方そのものは機械では見られない。直したあと実機で撮り直し、縦に並んだ石が 1 つずつ離れて見えることを確かめた（下の写真）。施主の確認は未

## 結果

- 撮り比べた写真（作業木の外・スクラッチパッドの `igo-shots/`）: `mid.png`（直す前・柱に見える）・`underline.png`（直した後・同じシード 3 のほぼ同じ手数）・
  `end.png`（直した後の終局の画面・`W+122.5`・秒読み）
- 隙間は下線の太さ（数ピクセル）なので、Reversi の 1 行の隙間より細い。石の数は数えられるが、細さが十分かは施主に見てもらう
- 256 色の端末でも SGR 4 は効く。下線を描かない端末では、直す前（柱）の見え方に戻るだけで、壊れはしない
- 撮影の手順（`wt.exe` を配列の引数で起動・`FindWindow` にクラス名・`PrintWindow` の 2・自分の実行ファイルだけを `pkill -f '^<フルパス>'`）は README の写真（Phase 4）でもそのまま使う

## 却下した選択肢

| 選択肢 | 却下の理由 |
| --- | --- |
| 1 交点 2 行（行のあいだを碁盤の地にする） | 19 路が 38 行になり、Windows Terminal の既定の 30 行に入らない |
| 石のセルに `_` などの文字を前景色で書いて隙間を作る | 石のセルに文字を書かない規則（WORK-ORDER 第 2-3 節の 4）に反する。字形は端末とフォントで位置が変わる |
| 半分の高さのブロック文字（`▄`）で石を描く | ASCII 以外の文字で、幅の罠に戻る（ADR 0007） |
| 縦に隣り合う石の色を行ごとに少し変える | 同じ色の石の色が 2 つになり、テーマの色の正本が割れる。縞に見える |
| 何もしない（囲碁の石は実際の碁盤でも接している） | 写真で 1 本の柱に見え、石を数えられなかった |
